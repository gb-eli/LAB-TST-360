# Perfis Visuais Setoriais — v0.35

Cada perfil define:
- cor de identidade;
- cor base de piso;
- família de material;
- cor secundária;
- layout de dressing.

Exemplos:
- Porto → asphalt;
- Saúde → tile;
- Escritório → wood;
- Indústria/Elétrica → epoxy;
- Construção/Almoxarifado/Oficina → concrete.

Os materiais são estilizações didáticas e não reproduções certificadas de acabamentos reais.
