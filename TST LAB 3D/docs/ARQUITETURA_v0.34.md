# Arquitetura v0.34 — G10.4

A v0.34 não muda o núcleo modular da plataforma. Ela melhora a camada de apresentação e os viewers já existentes.

## Principais componentes atualizados
- `object-focus-viewer.js`
- `panorama360-viewer.js`
- `environment-experience-hub.js`
- `environment-visual-tour.js`
- `css/base.css`
- `css/layout.css`
- `css/labs.css`

## Estratégia
1. aumentar percepção de qualidade visual;
2. manter carregamento sob demanda;
3. manter compatibilidade com GitHub Pages;
4. não criar dependência de pós-processamento pesado.
