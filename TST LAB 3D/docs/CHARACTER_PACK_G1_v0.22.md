## LOD

### LOD0

- menos adornos;
- menos primitives;
- indicado para Médio.

### LOD1

- botas;
- luvas;
- identificação/detalhes adicionais;
- indicado para Alto/Ultra.

## Escopo

O Character Pack G1 serve como **prova funcional do pipeline humano skinned**.

Ele não é o nível final de modelagem humana do TST 360.
