# Investigação de Acidentes — G7

Laboratório híbrido 2D/3D para análise didática de evidências e reconstrução de um caso simulado.

## Recursos
- cinco evidências clicáveis;
- cena forense 3D orbital;
- foco de câmera em evidências;
- reconstrução em três estados: antes, momento crítico e pós-ocorrência;
- captura PNG da vista 3D;
- hipótese de causa e medida preventiva;
- relatório JSON;
- fallback 2D completo.

A reconstrução é educacional e não deve ser tratada como prova de causalidade de um acidente real.
